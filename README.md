# Rangmanch

A theatre based booking startup, needs a reviews API so audiences can rate and reviews plays. The API powers their app's review section and average rating displays.

A full CRUD API backed by SQLite.

# SQL Model for database models(combines SQLAlchemy + Pydantic)
# SQLite as a zero-config database
# FastAPI lifespan events for startup/shutdown logic
# Session dependency injection
# Pagination with skip/limit
# Aggregation queries(Average rating)
